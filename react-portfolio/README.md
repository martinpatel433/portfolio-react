# React Portfolio

A personal portfolio website built with React and Vite. The app showcases a developer profile, skill highlights, featured work, blog links, and a contact section.

## Features

- Modern responsive portfolio layout
- Hero/slider section for introduction
- Skills showcase
- Work/project section
- Blog highlights
- Contact and footer sections
- Fast development setup with Vite

## Tech Stack

- React
- Vite
- CSS
- Lucide React icons

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

4. Preview the production build locally:
   ```bash
   npm run preview
   ```
